# PortfolioPath v27 — Beginner Workflow Simplification

Implemented September 2026 changes:

- Renamed the Alpha navigation area to Profile and replaced the alpha-readiness page with an account/profile page.
- Removed Practice Transactions and Performance from the user-facing product, including their routes, progress steps, navigation, and performance snapshot UI.
- Removed Purpose from Create Portfolio; all portfolios remain educational learning portfolios internally.
- Fixed questionnaire investment amount entry so it starts blank, accepts arbitrary values, and can be cleared cleanly.
- Fixed builder allocation entry so fields start blank and edits are saved on blur/Enter instead of writing on every keystroke.
- Removed portfolio comparison UI from the builder.
- Removed the manual “Refresh with live data” builder action.
- Changed in-app research data to a monthly refresh model (up to 30 days old) and added visible freshness language.
- Expanded beginner discovery in the builder: 12 default options plus guided “Show me” browsing for ETFs, lower risk, quality, growth, and dividends.
- Retained search and full-category browsing for users who know a ticker or company name.
- Removed performance dependence from Insights, Alerts, and Portfolio Review.
