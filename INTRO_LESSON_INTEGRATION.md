# Interactive Learn the Basics integration

PortfolioPath now includes a 10-step interactive beginner lesson at `/learn/basics`.

## Entry points
- New portfolio creation routes to the lesson before the questionnaire.
- Users can choose **Skip for now** and continue immediately.
- The Dashboard highlights **Learn the Basics — 3 min**.
- The Learning Center permanently links to the lesson.
- The questionnaire links back to the lesson and returns to the same questionnaire when completed or skipped.

## Interactions
- Back / Next navigation
- Clickable progress dots
- Progress bar and slide count
- Diversification quick check
- Research-source quick check
- Completion marker stored locally in the browser
- Responsive mobile layout
- Reduced-motion support inherited from the existing global accessibility rules

## Content change
The risk/return scale now says **Generally lower risk / lower return potential** and **Generally higher risk / higher return potential** rather than presenting the relationship as absolute.
