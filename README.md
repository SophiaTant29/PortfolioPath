# PortfolioPath

PortfolioPath is an interactive investing education and portfolio-simulation platform for beginners. It teaches how diversification, asset allocation, investment research, risk, and portfolio structure work through a guided build experience.

## Current status
**Launch-ready demo / public-launch candidate.** The product is polished for demonstrations and user testing. Operational launch steps are documented separately for the day public signup is opened broadly.

## Core experience
1. Learn key investing terms.
2. Create a learning portfolio.
3. Complete an investor-profile exercise.
4. Review an educational model allocation.
5. Enter an investment amount or use percentages only.
6. Build category by category with amount-aware complexity.
7. Research examples and select holdings.
8. Review diversification, concentration, ETF overlap, and learning takeaways.

PortfolioPath is for education and simulation. It does not execute trades and is not designed to provide individualized buy/sell/hold instructions.
